    wifipilot
    
        
    A wifite alternative in Python for authorised WiFi, Bluetooth and IT-device
        assessments: — attacks across three editions,
        an optional local-LLM advisor (the deterministic planner can run everything),
        multiprocessing/GPU cracking, and a simulation mode that runs the identical
        pipeline with no hardware.
